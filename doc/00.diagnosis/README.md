# 이 폴더는 기록이다 — 지금 상태가 아니다

이 리포가 **지금 모습이 된 경위**를 남긴 것이다. 진단 → 재설계 → 실측 → 수정 순서로 쌓였다.

**파일 이름과 본문의 `v1`·`v2` 는 당시 표기다.** 그때는 리포가 둘이었다 —
앞선 판(`flow-sdlc`)과 다시 지은 판(`flow-sdlc-v2`). **다시 지은 판이 지금 이 리포다.**
이름을 고치지 않는다: 상호 참조가 서로를 그 이름으로 가리키고, **기록을 나중 사정에 맞춰 고치면
기록이 아니게 된다.**

| 무엇 | 어디 |
|:--|:--|
| 앞선 판의 결함 진단 | `diag-A-commands-agents.md` · `diag-B-skills.md` · `diag-C-infra.md` |
| 설계 반증 리뷰 | `review-v2-design.md` · `review-v2-design-2.md` · `review-v2-final.md` |
| 구현 리포트 | `impl-skills-report.md` · `T*-report.md` · `redesign-W*.md` |
| 세션이 끊긴 뒤 이어받은 기록 | `review-v2-resume.md` |
| **실제로 깔아 돌린 실측** | `trial-yt-digest/` — `COVERAGE.md` 가 판정, `logs-*/` 가 원문 |

**지금 상태를 알려면 여기가 아니다** — 구조는 `../01.architecture.md`, 잣대는 `../00.concept.md`,
남은 것은 `../04.redesign.md` 와 `trial-yt-digest/COVERAGE.md` 다.
