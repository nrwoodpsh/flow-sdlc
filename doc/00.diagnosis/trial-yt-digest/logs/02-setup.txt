## 알아둘 것

- **훅은 `git config` 로 걸었고 이 설정은 커밋되지 않습니다.** clone 한 사람은 `.githooks/pre-commit` 파일이 있어도 `git config core.hooksPath .githooks` 를 다시 돌려야 훅이 돕니다.
- **유닛이 아직 없어 쓰기 게이트는 `no-units` 로 전부 통과합니다.** 첫 task 문서가 생기는 순간부터 File Map 밖 소스 쓰기가 막힙니다 — 그때 레거시 4개 파일에서 막히면 면제를 승인받아 넣으면 됩니다.
- 도구 중 권할 것: TypeScript LSP (`/plugin install typescript-lsp@claude-plugins-official`, 사용자 설치) — 없어도 grep 으로 동작하지만 `/flow:build`·`/flow:review` 정확도가 떨어집니다.
