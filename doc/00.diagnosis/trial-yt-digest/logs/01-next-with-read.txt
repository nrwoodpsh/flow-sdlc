## 승인

```
[/flow:next] 작업: yt-digest 에 flow 층 도입 · 유형: 레거시(스켈레톤)
             갈 곳: /flow:setup
             근거: workflow.config.json 이 없다 — 설정이 없으면 무엇을 물었든 setup 이 먼저다
             갈림길: 없음
             이어 돌리기: 안 함 (인자 비었음)
             → 이대로 할까요?  [실행 / 고치기 / 취소]
```

`setup` 다음은 위상상 `prd` 또는 `design` 이다. 무엇을 만들 차례인지는 setup 이 끝난 뒤 다시 계산한다.

이어서 돌리려면 `/flow:next 이어서` 로 불러 달라 — 그러면 전환마다 `gatekeeper` 를 태우고 커밋 직전에 멈춘다.
