### 원가 검증 주장의 범위

측정된 명제는 **"우리 코드가 내는 요청 수 ≤ 설정 N"** 이다. **"≤ 제공자 쿼터" 가 아니다.** 실제 유튜브 쿼터 값·리셋 시각이 미확인으로 남아 있고(`0.requirement.md:85-86`), 창 시작이 UTC 자정인 것이 제공자 리셋과 같다는 근거도 없다. "쿼터를 지킨다" 로 넓혀 적으면 미측정 명제를 통과로 적는 것이다.

실제 유튜브 API 호출 측정은 **요구하지 않는다** — 요구에 없는 측정 방법을 발명하는 것이고, `5.verify/01.md:13` 의 비용 상한과 충돌하며, 부를 진입점이 없다.

### 역산 표기

`quota.test.ts:17-20` 의 `dailyCallLimit === 100` 단언 한 건은 순수 현행값 고정이라 **요구 판정이 아니라 현행값 회귀 고정**이다. `100` 의 출처 미결은 요구 표가 아니라 미결 목록(`0.requirement.md:86`)에 남는다 — 등급을 내리지 않는다. 요구의 명제가 매개적("설정 상한 **N** 에서 N회까지")이고 `quota.test.ts:154` 가 N=2 에서 독립 검증하므로 판정이 숫자 `100` 에 매달려 있지 않다. 출처가 코드라는 흔적이 세 곳(`0.requirement.md:29`·`quota.ts:20`·`5.verify/01.md:43`)에 공개돼 있어 숨은 역산이 아니다.
