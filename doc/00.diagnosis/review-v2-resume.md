## 4. 개선 리포트 — 우선순위

> 절차·에이전트 본문의 산문 참조는 아무도 안 봤다.

## 6. 정리

**v2 는 "거의 끝났고 커밋이 안 됐다"** 가 정확한 상태다. 진단 3건이 짚은 것은 실측으로 닫혔고,
검사기·훅·생성물 대조가 전부 통과한다. 남은 것은 **성격이 다르다** —

- **위험**(P0·P2): 백업도 배포 경로도 없다. 설계 문제가 아니라 운영 문제다.
- **누락**(P1): 내 진단의 두 목록 사이로 빠진 검사 6종. 되살리는 비용이 작다.
- **미완**(P3·P4): 설계가 약속했으나 구현 안 된 것 하나, 값이 낮은 것 하나.
