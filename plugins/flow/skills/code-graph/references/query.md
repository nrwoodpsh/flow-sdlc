# 두 모드와 질의

## Joern 이 기본이다

`[필수]` 도구다. 이 스킬의 목적이 그래프 질의이고, 그게 없으면 목적이 사라진다. **축소 모드는 예외 경로다.**

| 언제 축소로 내려가나 | |
|:--|:--|
| Joern 이 설치돼 있지 않다 | 설치를 안내하고 축소 모드로 진행 |
| **파싱이 실패한다** | 언어 프론트엔드가 그 코드를 못 다룬다 |
| **그래프가 빈약하다** | 노드·엣지가 거의 안 나온다 — 그 언어 지원이 얕다는 뜻 |

**둘은 할 수 있는 일이 다르다.**

| | **그래프 모드** (Joern) | **축소 모드** (LSP) |
|:--|:--|:--|
| 전이적 영향 | ✅ 홉 제한 없음 | 🟡 **1~2홉까지만** |
| 데이터 흐름(taint) | ✅ | ❌ **불가능** |
| 속성 질의 | ✅ | ❌ |
| 코드 안 문자열 (`@Qualifier("...")`) | ✅ 리터럴 노드 | 🟡 grep 으로 |
| 정확도 표기 | `높음` | `보통` (LSP 없으면 `낮음`) |

**언어를 미리 재단하지 않는다.** Joern 프론트엔드는 넓다 — C/C++ · Java · JVM 바이트코드 · Python · JS/TS · Go · Kotlin · PHP · Ruby · Swift · C#. 정확도는 언어마다 다르니 **돌려보고 판단하고, 그 판단을 기억하지 않는다** — 프로젝트마다 다르고 버전이 오르면 달라진다.

## grep 은 두 모드에서 다 돈다

겹치는 것 같지만 **CPG 에 아예 안 들어가는 파일**이 있어서다.

| 어디 | CPG 에 있나 |
|:--|:--|
| `application.yml` · `.properties` · `.env` | ❌ 프론트엔드가 없다 (코드가 아니다) |
| `.sql` 마이그레이션 | ❌ |
| HTML·템플릿 · i18n `.json` | ❌ |
| 스코프 밖 파일 | ❌ (스코프를 좁게 잡았으니) |
| 파싱 실패한 파일 | ❌ |

- 그래프 모드에서는 **코드가 아닌 파일**만 훑는다. 코드 안 문자열은 Joern 이 이미 리터럴 노드로 봤다.
- 축소 모드에서는 **코드 안 문자열까지** 훑는다. LSP 가 그걸 못 본다.

## 그래프 모드 절차

**스코프를 한정한다** — 변경 파일과 그 모듈만 파싱한다.

```
joern-parse {대상 경로} --output cpg.bin
```

**목적에 맞는 것만 묻는다.**

| 목적 | 무엇을 묻나 |
|:--|:--|
| **영향 범위** | 이 메서드에 **도달하는 모든 호출 경로** (역방향 전이) |
| **회귀 표면** | 이 시그니처·필드를 **쓰는 모든 곳** + 그 호출자 |
| **taint** | 외부 입력에서 **위험한 곳**(SQL·셸·경로·역직렬화)까지 경로가 있나 |
| **비밀값 누출** | 비밀 필드에서 **로그·응답·외부 호출**까지 경로가 있나 |
| **속성 검색** | 조건을 만족하는 노드 전부 — 예: 인증 검사 없이 DB 쓰기에 닿는 엔드포인트 |

- 결과가 100건을 넘으면 **스코프가 넓다는 뜻**이다 — 좁혀 다시 묻는다.

## 축소 모드 절차

대상 심볼을 함수·클래스·필드 단위로 확정하고 **홉을 끊어** 전개한다.

| 홉 | 무엇 | 언제까지 |
|:--|:--|:--|
| 0 | 바뀐 심볼 | 항상 |
| 1 | 직접 부르는 곳 · 부르는 대상 (LSP 참조·정의·구현) | 항상 |
| 2 | 1홉의 호출자 | **공개 API·계약·참조 10곳 초과**일 때만 |
| 3 이상 | — | **하지 않는다.** `여기서 끊음` 에 적는다 |

그리고 **못 하는 것을 명시한다** — 데이터 흐름·전이적 도달성·속성 질의. **"안 했다"고 적는다.**

## 반환 형식

부르는 쪽이 그대로 쓸 수 있게.

```
대상: UserService.validateToken()
모드: 그래프 (Joern) · 스코프 src/user/**
정확도: 높음

영향 (전이적)
  1홉  AuthFilter.java:42 · LoginController.java:88
  2홉  ApiGateway.java:120  ← AuthFilter 경유
  구현체 MockUserService.java:15 (테스트)

흐름
  taint  없음 — 외부 입력이 SQL·셸에 닿는 경로 없음
  누출   ⚠ token 필드 → logger.debug (AuthFilter.java:51)

CPG 밖 (grep — 파싱 대상 아님)
  application.yml:12  "userService"
  V3__add_token.sql   token 컬럼 참조

테스트
  UserServiceTest.java (12건) · AuthFilterTest.java (3건)

확인 필요
  ReflectionUtils 동적 호출 — 문자열로도 안 잡힘

여기서 끊음
  없음 (전이 전체 계산)
```

축소 모드면 머리와 끝이 이렇게 바뀐다.

```
모드: 축소 (LSP + grep — Joern 없음)
정확도: 보통

여기서 끊음
  2홉 이상 · 데이터 흐름 추적 · 속성 질의  ← 전부 안 함
```
