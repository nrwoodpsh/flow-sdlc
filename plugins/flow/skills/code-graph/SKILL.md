# 코드 그래프 질의

코드를 **노드와 엣지**로 본다. 파일·텍스트가 아니라 **관계를 질의**한다.

| 노드 | 엣지 |
|:--|:--|
| 함수 · 메서드 · 클래스 · 파라미터 · 변수 · 리터럴 | 호출 · 데이터 흐름 · 제어 흐름 · 상속 · 소유 |

**왜 그래프인가** — 이 셋은 그래프 없이는 못 한다.

| 질의 | 그래프로 | 파일 읽기로 |
|:--|:--|:--|
| **외부 입력이 SQL·셸까지 닿나** | 엣지를 따라 도달성 계산 | **불가능** |
| **N홉 뒤에 무엇이 깨지나** | 전이적 도달성 한 번에 | 홉마다 후보가 곱해져 폭발 |
| **인증 없이 DB 쓰는 엔드포인트 전부** | 노드 속성 + 경로 조건 질의 | **불가능** |

## 어느 조각을 읽나

| 이 상황이면 | 반드시 읽는다 |
|:--|:--|
| 영향 범위·회귀 표면·데이터 흐름을 **질의한다** | `references/query.md` |
| 변경이 **계약을 건드린다** · MSA 다 · 다른 서비스가 부를 수 있다 | `references/service-boundary.md` |

두 번째 조각은 `impact-analysis`·`drift-check` 도 이름으로 가리킨다. **거기가 정본이라 옮겨 적지 않는다.**

## 경계

- **상시 인덱스를 만들지 않는다.** 부를 때 스코프만 계산하고 버린다 — 낡은 그래프가 틀린 답을 준다.
- **전체 코드베이스에 파싱을 돌리지 않는다.** 스코프는 변경 파일과 그 모듈이다.
- **질의문을 지어내지 않는다.** 질의 문법은 버전마다 다르다 — 확실치 않으면 축소 모드로 내려가 그렇게 적는다.
- **모드와 정확도를 반드시 표기한다.** 축소 모드 결과를 그래프 분석처럼 보고하지 않는다.
- **못 본 것을 안 본 것으로 적는다.** `여기서 끊음`·`확인 필요` 를 비우면 "다 봤다"로 읽힌다.
- **도구가 없다고 멈추지 않는다** — 축소 모드로 돌고 한계를 밝힌다.
- **결론만 반환한다** — 그래프·경로 원문을 메인 컨텍스트로 올리지 않는다. 그게 이 스킬을 쓰는 이유다.
