# 회귀 표면 뽑기

## 절차

**변경 심볼을 식별한다** — 수정할 함수·클래스·타입·엔드포인트·DB 컬럼을 명시한다.

**의존처를 전수 조사한다** — `code-graph` 에 넘긴다.

- **모드·정확도·`여기서 끊음` 을 함께 받는다.**
- 유닛을 넘으면 `explorer` 에 위임한다 — 메인 컨텍스트를 지킨다.

**영향을 판정한다** — 받은 목록을 이 셋으로 가른다.

| 판정 | 뜻 |
|:--|:--|
| 깨짐 | 시그니처·반환·에러계약이 바뀌어 호출부가 안 맞는다 |
| 동작 바뀜 | 컴파일은 되나 결과·부수효과가 달라진다 |
| 무관 | 영향 없다 |

**회귀 표면을 산출한다** — `깨짐`·`동작 바뀜` 목록을 task 의 `History` 아래에 적는다. 이탈과 같은 자리다.

- `code-graph` 의 **`확인 필요`·`여기서 끊음` 을 그대로 옮긴다.** 요약하며 지우지 않는다 — 안 본 범위가 사라지면 "다 봤다"로 읽힌다.
- **모드와 정확도를 함께 남긴다** — 축소 모드면 **데이터 흐름을 아예 안 봤다**는 뜻이다. 그걸 "영향 없음"으로 적지 않는다.
- **서비스 경계를 넘는 호출은 코드로 안 잡힌다.** 계약 범위가 `서비스 간`·`외부 제공` 이면 **`repo 밖 — 사람 확인`** 으로 적는다. 빼면 다른 서비스가 깨진다.

## 출력 형식

```markdown
### 회귀 표면 — {YYYYMMDD} · {변경 심볼}

모드 그래프(Joern) · 정확도 높음 · 스코프 src/user/**

| 판정 | 위치 | 왜 | 테스트 |
|:--|:--|:--|:--|
| 깨짐 | AuthFilter.java:42 | validateToken 반환형이 바뀐다 | 있음 |
| 깨짐 | ApiGateway.java:120 | AuthFilter 경유 (2홉) | **없음 — 미검증** |
| 동작 바뀜 | LoginCtl.java:88 | 만료 판정 시점이 달라진다 | 있음 |

### 안 본 범위

| 무엇 | 왜 |
|:--|:--|
| 여기서 끊음 — MockUserService.java:15 | 테스트 더블. 추적 중단 |
| **repo 밖 — 사람 확인** | 계약 `서비스 간` — order 서비스가 호출한다. **코드로 안 잡힌다** |
| 확인 필요 — 문자열 라우팅 | `handlers[name]` 동적 디스패치 |
```

- **모드가 축소면 `데이터 흐름 미확인` 을 안 본 범위에 적는다** — Joern 없이는 값이 어디까지 흐르는지 못 본다.
- **`안 본 범위` 를 비우지 않는다.** 빌 일이 없다 — 최소한 `여기서 끊음` 은 나온다. **비었으면 옮기다 지운 것이다.**
- **`무관` 판정은 적지 않는다** — 표가 길어지고 읽는 사람이 걸러야 한다. 센 개수만 한 줄로 적는다.
- 회차가 쌓이면 **날짜와 심볼로 구분해 덧붙인다.** 이전 회차를 지우지 않는다.
