# 영향 분석 (회귀 표면)

"이걸 고치면 저기가 깨지나" — 바꾸려는 코드에 **의존하는 모든 곳**을 변경 *전에* 찾아 사람 대신 체계적으로 확인한다. 테스트가 없는 곳의 회귀(초록불을 뚫는 회귀)를 예방한다.

## 절차

1. **변경 심볼 식별** — 수정할 함수·클래스·타입·엔드포인트·DB 컬럼을 명시한다.
2. **의존처 전수 조사** — `code-graph`에 넘긴다.

   - Joern이 있으면 전이적 영향과 데이터 흐름까지 그래프로 질의한다. 없으면 LSP·grep으로 1~2홉만 훑는다.
   - **모드·정확도·`여기서 끊음`을 함께 받는다.**
   - 유닛을 넘으면 `explorer`에 위임한다(`default-reference` 위임 판정) — 메인 컨텍스트 보호.
3. **영향 판정** — `code-graph`가 준 목록을 이 셋으로 가른다:

   | 판정 | 뜻 |
   |:---|:---|
   | 깨짐 | 시그니처·반환·에러계약이 바뀌어 호출부가 안 맞음 |
   | 동작 바뀜 | 컴파일은 되나 결과·부수효과가 달라짐 |
   | 무관 | 영향 없음 |

4. **회귀 표면 산출** — `깨짐`·`동작 바뀜` 목록을 task `History`에 적는다. 형식은 아래.
   - `code-graph`의 **`확인 필요`·`여기서 끊음`을 그대로 옮긴다.** 요약하며 지우지 않는다 — 안 본 범위가 사라지면 "다 봤다"로 읽힌다.
   - **모드와 정확도를 함께 남긴다** — 축소 모드(Joern 없음)면 **데이터 흐름을 아예 안 봤다**는 뜻이다. 그걸 "영향 없음"으로 적지 않는다.
   - **서비스 경계를 넘는 호출은 코드로 안 잡힌다** (`code-graph`). MSA에서는 **항상** 그렇다 — 계약 범위(`서비스 간`·`외부 제공`)를 회귀 표면에 **`repo 밖 — 사람 확인`** 으로 적는다. 빼면 다른 서비스가 깨진다.

## 출력 형식

task 문서의 **`History` 절 아래**에 붙인다 — 이탈과 같은 자리다(`02.task-doc`). `/flow:review`가 이 표를 체크리스트로 쓴다.

```markdown
### 회귀 표면 — {YYYYMMDD} · {변경 심볼}

모드 그래프(Joern) · 정확도 높음 · 스코프 src/user/**

| 판정 | 위치 | 왜 | 테스트 |
|:--|:--|:--|:--|
| 깨짐 | AuthFilter.java:42 | validateToken 반환형이 바뀐다 | 있음 |
| 깨짐 | ApiGateway.java:120 | AuthFilter 경유 (2홉) | **없음 — 미검증** |
| 동작 바뀜 | LoginCtl.java:88 | 만료 판정 시점이 달라진다 | 있음 |

### 안 본 범위

| 무엇 | 왜 |
|:--|:--|
| 여기서 끊음 — MockUserService.java:15 | 테스트 더블. 추적 중단 |
| **repo 밖 — 사람 확인** | 계약 `서비스 간` — order 서비스가 호출한다. **코드로 안 잡힌다** |
| 확인 필요 — 문자열 라우팅 | `handlers[name]` 동적 디스패치 |
```

- **`모드`가 `축소`면 `데이터 흐름 미확인`을 안 본 범위에 적는다** — Joern 없이는 값이 어디까지 흐르는지 못 본다.
- **`안 본 범위`를 비우지 않는다.** 빌 일이 없다 — 최소한 `여기서 끊음`은 나온다. 비었으면 옮기다 지운 것이다.
- **`무관` 판정은 적지 않는다** — 표가 길어지고 읽는 사람이 걸러야 한다. 센 개수만 한 줄로.
- 회차가 쌓이면 **날짜와 심볼로 구분해 덧붙인다.** 이전 회차를 지우지 않는다.

## 경계

- **못 찾았다고 "영향 없음"으로 단정 금지.** 동적 호출·리플렉션·문자열 라우팅은 grep에 안 잡힐 수 있다 — 불확실은 "확인 필요"로 표기.
- **repo·서비스 경계 밖을 "회귀 표면 없음"으로 적지 않는다.** 계약이 `서비스 간`·`외부 제공`이면 **호출부가 이 repo에 없을 수 있다** — `repo 밖 — 사람 확인`으로 남긴다.
- **초록불 ≠ 안전.** 영향처에 테스트가 없으면 통과해도 회귀 가능 — 반드시 사람에게 **미검증 목록**을 보고한다.
- 이 스킬은 **분석·리포트**다. 발견된 영향을 근거로 자율 수정하지 않는다(설계 이탈은 진입점으로 되돌아간다).
