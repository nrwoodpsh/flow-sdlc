# 템플릿에 없는 절을 요구할 때

**커맨드가 새 절을 요구하는데 프로젝트 템플릿에 그 절이 없을 수 있다.** 플러그인이 올라갔는데 템플릿을 동기화하지 않은 경우다.

```
/flow:prd (기능)  →  "업무 규칙을 적으시겠습니까?" (새 규칙)
                  →  프로젝트 템플릿에 그 절이 없다
                  →  어디에 쓰나?
```

| 하지 말 것 | 할 것 |
|:--|:--|
| 절을 조용히 지어내 추가한다 | **알리고 선택을 받는다** |
| 절이 없으니 그 내용을 버린다 | 버리면 규칙이 작동하지 않는다 |

```
ℹ️ `업무 규칙` 절이 프로젝트 템플릿에 없습니다.
   템플릿이 낡았고 이 규칙은 나중 판에서 추가됐습니다.
   ① 이 문서에만 절을 추가하고 진행    ② 템플릿부터 동기화 (/flow:setup)
```

- **①을 고르면 이 문서에만 절을 넣고 진행한다.** 템플릿은 안 건드린다 — 그건 `/flow:setup` 의 일이다.
- **②를 고르면 멈춘다.** 동기화 후 다시 부른다.
- **그 절이 채점되지 않는다는 사실을 함께 알린다** — 템플릿이 기준이라 절이 없으면 채점 대상이 아니다(`doc-verify`).
- **반대 경우(템플릿에 있는데 커맨드가 안 쓰는 절)는 건드리지 않는다.** 프로젝트가 추가한 절일 수 있다.
