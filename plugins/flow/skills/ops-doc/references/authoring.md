# 운영 절차 · 설명 노트

## 운영 절차 (SOP · 런북)

**따라 하면 되는 문서다.** 근거는 실제 명령·스크립트·CI 설정이고, 사람만 아는 권한·담당은 **물어본다.**

- **`되돌리기` 가 없으면 "되돌릴 수 없음"이라고 분명히** 적는다.
- **`담당` 표에 `사람만` 을 표시한다** — 운영 반영·권한 부여·과금·데이터 삭제. **표시가 없으면 AI 가 실행해도 되는 단계로 읽힌다.**
- 나중에 "이 절차대로 해줘"라는 요청이 오면 이 표시로 갈린다. 실행 규칙은 `safety.md` 가 정본이다.

## 설명 노트

**왜 이렇게 돼 있는지가 본체다.** 근거는 코드·`00.ref/`·ADR 이고 **새 결정을 하지 않는다.**

- **ADR 을 묶는 것이 주 목적이다.** 결정이 쌓이면 *"왜 이렇게 돼 있나"* 를 알려고 ADR 을 여러 개 읽어야 한다 — 그걸 한 글로 잇는다. `어디에 이어지나`·`더 볼 것` 절이 그 자리다.
- **문서 읽는 순서의 중간 단계가 이 문서다.** 비어 있으면 새 사람이 앞뒤를 건너뛴다.
- **부르는 곳이 없다** — 파이프라인이 만들지 않는다. 문서 리뷰가 *"ADR 은 쌓였는데 설명 노트가 없다"* 를 제안하고, 사용자가 직접 요청할 수도 있다.
