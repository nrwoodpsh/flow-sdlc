# 장애 회고

## 근거

로그·알람·배포 이력·`git log` 를 본다. **시각은 추정하지 않는다.**

## 쓰는 법

- **사람을 탓하지 않는다.**
- **`근본 원인` 은 증상과 구분한다** — "서버가 죽었다"는 증상이다.
- **재발 방지에 근본 원인과 닿는 항목이 하나도 없으면 회고가 끝난 게 아니다.**

## 재발 방지 조치마다 `어디로` 를 적는다

가는 곳은 시스템 요구 · 크로스커팅 규칙 · 도메인 규칙 · 수정 작업 · 운영 절차 신설 · ADR 중 하나다.

- **비우면 조치가 `04.ops/` 에 갇혀 아무도 안 본다.**
- **여기서 요구·규칙을 직접 쓰지 않는다.** 회고는 기록이고 등록은 그 커맨드가 한다 — 가는 곳만 적는다.
- **적어둔 것으로 끝나지 않는다** — 문서 리뷰가 `어디로` 의 ID 가 요구 등록소에 실제로 있는지 대조한다. 대조 표는 `doc-verify` 의 채점 조각에 있다.
- **`P1` 이 미등록이면 회고가 닫히지 않았다.**
