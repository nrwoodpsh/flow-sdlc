# 기본 참조 관리

Claude Code 는 자동 인덱싱이 없다 — 파일 참조는 명시해야 한다.

**커맨드별 자동 로드 목록은 여기 없다.** `flow.topology.json` 의 `commands.*.loads` 가 정본이고 각 커맨드의 연결 절은 그것의 생성물이다. 이 표를 스킬에도 두면 정본이 둘이 된다 — *"커맨드의 연결 절에 적는 것이 기제다"* 라고 적어 두고서 안 실리는 커맨드의 행까지 갖게 된다.

## 항상 참조 금지 — 자동 로드하지 않는다

필요하면 사용자가 `@` 로 명시 주입한다.

- `doc/01.work/{작업 중이 아닌 타 도메인}/`
- `spike/` — 버릴 실험 코드

`7.summary/`·`02.decisions/` 는 참조를 허용한다 — 이력·결정 맥락이 필요할 때 명시 주입할 수 있다.

## 큰 정본은 인덱스 먼저

아키텍처 문서·DB 스키마의 큰 본문은 인덱스만 훑고 필요한 파일만 선택 로드한다.

**인덱스가 없는 정본이 하나 있다 — 용어집이다.** 통째로 읽거나 안 읽는다.

- **설계 전 확인은 필수다** — 용어를 모르면 설계가 어긋난다.
- **커지면 공유하는 것만 남긴다** — 도메인 전용 용어는 그 도메인 파일로 옮긴다.
- **용어집이 길어지면 매 설계가 그 비용을 낸다.** 절을 나누는 것으로는 줄지 않는다 — **양을 줄여야** 한다.

## 경계

- **`@` 파일 주입은 한 턴에 최대 5개.** 단일 파일이 500줄을 넘으면 분할을 검토한다.
- **위임 판정을 각자 "많으면·넓으면"으로 판단하지 않는다** — 조각의 규칙을 따른다.
- **참조 금지 경로를 자동으로 읽지 않는다.**
- **사용자가 지정한 참조가 기본값을 덮지 않는다** — 더한다.
