# 판정 규칙 (정본)

**소스 변경이 있는데 작업 문서가 함께 오지 않으면 드리프트다.**

## 소스 판정 — 순서대로

| 순 | 규칙 |
|:--|:--|
| ① | **`drift.ignore` 에 맞으면 소스가 아니다** (기본: `**/*.md` · `**/*.test.*` · `spike/**`) |
| ② | **`drift.sourceGlobs` 가 있으면 그 안에 있는 것만 소스** (예: `src/**`·`app/**`) |
| ③ | 없으면 기본값 — **`doc/`·`spike/`·`.claude/`·`.github/` 밖이고 `.md` 가 아닌 것** |

- **`spike/` 는 소스가 아니다** — 버릴 실험 코드다. 유지보수 자산이 아니라 드리프트 대상이 아니다.
- **`.md` 는 소스가 아니다** — 문서 자체다.
- glob 에서 `**` 는 경로 구분자를 포함하고 `*` 는 포함하지 않는다. **`**/x` 는 최상위 파일에도 맞는다** — `**/*.md` 가 `README.md` 를 잡는다.

## 문서 판정

**`doc/01.work/` 아래 아무 것이나 함께 오면 인정한다.**

- `2.task/`·`3.contract/`·`5.verify/`·`7.summary/` **어느 것이든** 된다.
- **요약만 요구하지 않는다** — 작은 변경에 요약 작성을 강제하면 마찰이 커진다. 요약이 필요한지는 `/flow:sync` 가 판단한다.

## 못 잡는 자리가 하나 있다

**`doc/00.ref/` 는 이 판정이 안 본다.**

| 무엇 | 왜 안 잡히나 |
|:--|:--|
| **마이그레이션은 들어갔는데 `00.ref/02.db-schema/` 가 낡았다** | 스키마 문서는 `doc/` 아래라 **문서로 취급**된다. 소스(마이그레이션) + `doc/01.work/` 갱신이면 판정은 통과다 |

- **경로로 판정할 수 없다** — 마이그레이션 자리가 프로젝트마다 다르다(`db/migration`·`prisma/migrations`·`alembic/versions`). 훅·CI 에 넣으면 오탐과 미탐이 함께 늘어난다.
- **커밋 준비에서 변경 내용을 보고 확인한다.** 차단이 아니라 확인이다.
- **원래 자리는 구현 국면이다** — 마이그레이션을 돌린 그 자리에서 스키마 문서를 갱신하면 커밋 확인에 걸릴 일이 없다.

## 세 겹 — 어디서 어떻게 걸리나

같은 규칙을 세 곳이 쓴다. **판정은 같고 강도만 다르다.**

| | 어디 | 언제 | 무엇 |
|:--|:--|:--|:--|
| ① | **`/flow:commit`** (이 스킬) | 커밋 준비 | **확인** — 사용자가 판단한다 |
| ② | **git 훅** `drift-hook.sh` | `pre-commit` | **차단** (`exit 1`) |
| ③ | **CI 워크플로** | PR | 머지 차단 (**옵트인**) |

- **②는 도구와 무관하다** — Sourcetree·IDE·CLI 어디서 커밋해도 걸린다. **①이 안 도는 경우를 잡는 것이 ②의 유일한 일이다.**
- **②에 설정 키가 없다.** 켜고 끄는 것은 훅을 깔거나 빼는 것으로 한다 — 범위는 `sourceGlobs`·`ignore` 로 조절한다.
- **②는 유닛이 하나도 없으면 그냥 통과한다.** 레거시에 막 깔았을 때 모든 커밋을 막으면 못 쓴다. 첫 유닛이 생기면 켜진다.
- **`--no-verify` 로 ②를 넘길 수 있다** — 그래서 가드가 `--no-verify` 를 차단한다. 우회를 막으려면 ③을 켠다.

## 커밋 준비 절차

`git status`·`git diff --stat` 로 이번에 커밋될 변경을 모으고 위 규칙으로 소스·문서를 가른다. 드리프트면 경고를 제시한다.

```
⚠ 드리프트 의심: 소스가 변경됐으나 작업 문서가 이번 커밋에 없습니다.
  변경 소스: src/user/UserService.java
  대응 유닛: doc/01.work/user/00.login/ (미포함)
  → /flow:sync를 먼저 돌릴까요? 아니면 문서 갱신이 불필요한 변경입니까?
```

사용자 판단을 받는다. 동기화가 필요하면 커밋을 멈추고 안내하고, 불필요하면 진행한다.
