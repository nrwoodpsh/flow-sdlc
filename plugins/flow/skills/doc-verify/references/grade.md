# 절의 등급 (정본)

템플릿의 절마다 등급이 붙어 있다. **등급이 판정 강도를 정한다.** 등급을 쓰는 쪽이 여기 하나라 정본이 여기다 — `doc-template` 에 같은 표를 두지 않는다.

| 등급 | 표기 | 뜻 | 안 채우면 |
|:--|:--|:--|:--|
| **진행 필수** | `**[진행 필수]**` | **다음 커맨드가 이 내용을 소비**한다. 없으면 진행 불가·추적 끊김 | **FAIL** — `gatekeeper` 도 **차단**한다 |
| **문서 필수** | `**[문서 필수]**` | **업계 표준이 요구**한다. 기계는 안 읽지만 **사람이 읽는다** | **FAIL** — 다만 `gatekeeper` 는 **차단하지 않는다** |
| 선택 | `*(선택)*`·`*(해당 시)*`·표기 없음 | 있으면 좋다 | 표시만 |

- **표기가 없으면 선택이다.** 기본값이 선택이라 새 절을 추가할 때 부담이 없다.
- **프로젝트가 절을 더해도 된다** — 그 프로젝트만의 것(규제 근거·정산 대조 등)은 표기 없이 넣는다. 채점 대상이 아니다.
- **등급을 커맨드가 바꾸지 않는다.** 템플릿에 적힌 것을 따른다.

## 진행 필수 — 누가 소비하나

| 절 | 소비하는 곳 |
|:--|:--|
| 요구 (ID·완료 기준·측정 방법) | 설계의 태그 · 커버리지 감사 · `gatekeeper` |
| 시스템 요구 *(횡단 제약이 있을 때만)* | 같음 — **`SYS-*` 가 0개면 비는 게 정상**이다 |
| 설계 요소 (`D-N` + 충족 요구) | 설계를 task 로 쪼개는 쪽 |
| task 의 frontmatter 태그 | 태그 grep · 되돌아갈 범위 계산 · **기계 게이트의 판정 근거** |
| task 의 `Logic`·`File Map`·`Verification` | `builder` 구현 · `impact-analysis` · 검증 |
| 검증 결과의 판정 (첫 절) | **`gatekeeper` 가 PASS/FAIL 을 여기서 읽는다** |
| 검증 결과의 완료 기준 매핑 | 커버리지 감사 |
| 검증 결과의 `미검증` | **다음 범위가 여기를 모아 가서 닫는다** — 비면 규칙이 검증 없이 사라진다. 없을 때도 `없다` 로 적는다 |
| 리뷰의 판정 (첫 절) | **`gatekeeper` 가 미해결 critical 을 여기서 읽는다**(전 회차 누적) · `/flow:commit` |
| 리뷰의 발견 (severity) | `gatekeeper` critical 확인 · `/flow:commit` |
| task 의 `사용 계약` *(계약을 쓰는 task 만)* | **계약은 task 와 M:N** — 여기가 유일한 추적 자리다. 비면 계약 변경의 영향 task 를 못 찾는다 |
| 외부 의존의 `우리 요구와 맞나` *(행이 있을 때만)* | `gatekeeper` — **`충돌` 이면 설계 착수 금지** |
| 도메인 문서의 `유닛 계획` *(요구가 확정일 때만)* | 기능 레벨 요구 발급의 진입 대상 |
| 유스케이스 상세의 업무 규칙 *(규칙이 있을 때만)* | `testing` 이 **경계값 테스트를 도출**한다 — 없으면 규칙이 검증되지 않는다 |
| 도메인 문서의 업무 규칙 *(규칙이 있을 때만)* | 같음 — 도메인의 여러 유스케이스가 공유하는 규칙 |

## 문서 필수 — 어느 표준이 요구하나

| 절 | 표준 |
|:--|:--|
| 도메인 문서의 경계 *(도메인이 둘 이상일 때만)* · 용어 | DDD — Bounded Context · Ubiquitous Language |
| 아키텍처 문서의 크로스커팅 규칙 · 목표 · 외부 의존 | arc42 |
| 결정 · 기각 대안 | ISO/IEC/IEEE 42010 rationale · MADR |
| 요구의 액터 | UML 유스케이스 |
| 검증 결과의 결함 | ISO/IEC/IEEE 29119-3 Incident Report |

> **왜 표준을 따르나** — 6개월 뒤 다른 사람이 읽는다. `결정·기각` 이 없으면 **같은 논쟁을 다시** 하고, `용어` 가 없으면 **같은 말을 다르게** 쓴다. 기계는 안 읽지만 사람이 읽는다.

## 조건절이 붙은 절

**조건 확인 없이 FAIL 로 적지 않는다.** `SYS-*` 가 0개인 것은 정상이다 — 작은 도구엔 횡단 제약이 없다.
