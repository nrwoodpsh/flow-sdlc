# 유닛 상태 · 재개 지점

`/flow:sync` 가 유닛 README·도메인 문서의 `하위 기능` 에 적는 값이다. **값의 정본은 여기** — 다른 말을 쓰지 않는다.

**상태의 정본은 파일이고 README 는 캐시다.**

| | 무엇 |
|:--|:--|
| **파일** | **정본** — 언제 봐도 맞다 |
| README 의 `상태` | **캐시** — `sync` 를 돌린 시점의 값이다. **낡을 수 있다** |

구현 중간에 멈추면 `sync` 를 안 돌린 상태다 — README 는 `명세` 인데 `4.build/` 가 이미 있다. **README 를 믿지 않고 파일을 센다.**

| 상태 | 판정 근거 (폴더·파일로 계산) |
|:--|:--|
| `설계` | `0.requirement`·`1.design` 은 있고 `2.task` 가 없다 |
| `명세` | `2.task`·`3.contract` 는 있고 `4.build` 가 없다 |
| `구현중` | `4.build` 는 있고 `5.verify` 판정이 PASS 가 아니다 |
| `검증됨` | `5.verify` 판정이 PASS 다 |
| **`정지`** | **국면이 멈췄다** — 아래 |

## task 단위 — 어디까지 됐나

**유닛 상태만으로는 재개 지점을 모른다.** task 가 5개인데 `구현중` 이면 몇 번까지 됐나.

**스파인이 1:1이라 번호로 센다** — `2.task/NN` ↔ `4.build/NN` ↔ `5.verify/NN`.

| task NN | 있는 것 | 상태 |
|:--|:--|:--|
| `2.task/NN.md` 만 | — | **미착수** |
| + `4.build/NN.md` | 구현 기록 | **구현됨, 미검증** |
| + `5.verify/NN.md` 판정 FAIL | 실패 기록 | **검증 실패** |
| + `5.verify/NN.md` 판정 PASS | — | **완료** |

```
2.task/    00.login-api.md  01.session.md  02.lockout.md
4.build/   00.login-api.md  01.session.md                  ← 02가 없다
5.verify/  00.login-api.md                                 ← 01이 미검증
           ↓
재개 지점: 01 검증 → 02 구현
```

- **`/flow:build` 의 미완료 task 자동 식별이 이 규칙이다.** `2.task/NN` 이 있고 `4.build/NN` 이 없는 것이 미완료다.
- **번호가 빠져 있으면(`00`·`02` 만 있고 `01` 없음) 그 사실을 알린다** — 스파인이 깨졌다는 뜻이다.
- **`5.verify/NN` 의 판정은 `판정` 절 첫 줄을 본다.**

## 재개할 때는 다시 계산한다

**새 세션이 붙으면 README 를 믿지 않고 파일을 센다.**

| 누가 | 언제 |
|:--|:--|
| `/flow:next` | 사용자가 "이어서 하고 싶다"고 할 때 · 어느 국면부터 돌지 정할 때 |
| `/flow:build` (인자 비움) | 대상을 자동 식별할 때 |

- **앞선 단계를 먼저 닫는 쪽을 권한다** — 미검증을 두고 다음 task 를 구현하면 실패가 쌓인다.
- **계산한 상태가 README 와 다르면 알린다** — `sync` 를 안 돌린 것이라 `sync` 를 권한다.
- **README 를 여기서 고치지 않는다** — 색인 갱신은 `/flow:sync` 의 일이다.
- **오래된 맥락은 문서에 있다** — task `History` 의 이탈 기록·`6.review/` 의 미해결·`확인 필요` 절을 함께 읽어 보여준다.

## `정지` 는 사유를 함께 적는다

안 적으면 `구현중` 과 구분이 안 된다.

| 사유 | 언제 |
|:--|:--|
| `정지(빌드 3회)` | 구현↔테스트 루프 3회 실패 |
| `정지(critical)` | 리뷰 critical 미해결 |
| `정지(요구)` | 요구 충돌·쿼터 충돌 — 사람이 정해야 한다 |
| `정지(되돌아가기 2회)` | 두 번 고쳐도 안 됐다 (`revert-scope.md`) |

- **손으로 정하지 않는다** — 폴더와 판정 파일에서 계산한다.
- **`정지` 를 `구현중` 으로 적지 않는다.** 멈춘 것과 진행 중인 것은 다르다 — 색인만 보고 무엇이 막혔는지 알아야 한다.
- `5.verify` 가 여러 회차면 **최신 회차의 판정**을 본다. 단 리뷰 critical 은 **전 회차 누적**이다(`code-review` 의 등급 조각).
