# ID 체계

**한 문서 안에서 쪼개지는 것에만** ID를 준다. task 이하는 **파일 경로가 곧 ID** — 별도 번호를 만들지 않는다.

| 층 | 형식 | 예 | 범위 |
|:--|:--|:--|:--|
| 요구 | 레벨별 (`level.md`) | `SYS-1` · `USER-3` · `USER-LOGIN-1` | 전역 |
| 설계 요소 | `D-N` | `D-1` | 문서 내 로컬 (전역 지칭은 `user/00.login#D-1`) |
| **화면** | **`SCR-N`** | `SCR-1` · `SCR-12` | **전역** — 아래 |
| task 이하 | — | `2.task/00.login-api.md` | 경로가 ID |

## 화면은 왜 전역인가

| | 참조 범위 |
|:--|:--|
| `D-N` 설계 요소 | 같은 유닛의 task 만 가리킨다 → **로컬로 충분** |
| **`SCR-N` 화면** | **화면 이동이 유닛·도메인을 넘는다** — 로그인(`admin/00.login`)에서 대시보드(`admin/01.dashboard`)로 간다 |

- **유닛마다 `SCR-1` 부터 시작하면 안 된다.** 같은 번호가 여러 곳에 생겨 이동을 못 가리킨다.
- **발급은 아키텍처 문서의 `화면 지도` 에서** 한다 — 거기가 화면 목록의 정본이다. 유닛 설계도는 발급받은 번호를 쓴다.
- **FE 가 없는 프로젝트는 이 ID를 쓰지 않는다.**

## 이름에서 ID 만들기

**번호를 떼고 대문자로.** 하이픈은 그대로 둔다.

| 레벨 | 어디서 따오나 | 예 |
|:--|:--|:--|
| 시스템 | 고정 | `SYS-1` |
| 도메인 | `01.domain/{도메인}.md` 의 **도메인 이름** | `collect.md` → `COLLECT-1` |
| 기능 | `01.work/{도메인}/{NN.유닛}/` 의 **도메인 + 유닛** | `shorts/00.script-gen/` → `SHORTS-SCRIPT-GEN-1` |

- **번호는 항상 마지막 조각이다.** 첫 조각이 도메인, 가운데가 전부 유닛 이름 — 하이픈이 몇 개든 이 규칙으로 갈린다.
- **약칭을 만들지 않는다.** `SHORTS-SCRIPT-GEN-1` 이 길다고 `SSG-1` 로 줄이면 무엇의 약자인지 아무도 모르고, 폴더↔ID 매핑표가 또 생긴다.
- **짧은 폴더명이 짧은 ID를 만든다.** 한 단어가 좋고 두 단어까지다 — `login`·`collect`·`script-gen`. 서술형(`make-shorts-from-report`)을 쓰지 않는다.

## 유닛 폴더명을 바꾸지 않는다

폴더명이 ID의 일부라 이름을 바꾸면 **발급한 ID가 전부 바뀐다.**

| 무엇이 함께 걸리나 | |
|:--|:--|
| 요구·설계·task 의 태그 | `{도메인}-{유닛}-N` 을 가리키는 것 전부 |
| `2.task`↔`4.build`↔`5.verify` 스파인 | 번호 1:1이 폴더 기준이다 |
| 화면 지도의 `소속` | 어느 유닛이 만드는 화면인가 |
| **코드의 import 경로** | 계약·프롬프트를 유닛 폴더에서 직접 읽는다 |

- **이름이 마음에 안 들면 그대로 둔다.** 폴더명은 사람이 읽는 이름이 아니라 **주소**다.
- **범위가 실제로 달라졌으면** 그 유닛을 `~~취소~~` 로 닫고 **새 유닛을 만든다** — 고치는 것이 아니라 대체하는 것이다. 닫은 유닛의 요구는 `deprecated` 로 남긴다.
- **처음 만들 때 잘 정한다** — `/flow:design` 의 도메인 레벨 `유닛 계획` 이 그 시점이다.

## 발급 규칙

- **불변·append-only** — 번호 재편 금지. 삭제는 `~~USER-3~~ (deprecated)`, 분할은 하위 ID(`USER-3` → `USER-3.1`·`USER-3.2`). 기존 파일이 있으면 이어서 발급한다.
- **부모는 문서 상단에 한 번** — `상위: USER-1 ← SYS-1`. 각 요구에 중복 기재하지 않는다.
- **부모가 있는 것은 기능 요구뿐이다** — `{도메인}-{유닛}-N` 의 부모는 `{도메인}-N` 이다. 도메인 요구엔 부모가 없다.
- **`SYS-*` 는 횡단 제약이라 특정 도메인의 부모가 아니다** — 설계 요소가 직접 태그한다(`tagging.md`).
- **적정 입도** — 너무 잘게·너무 크게 쪼개지 않는다.
