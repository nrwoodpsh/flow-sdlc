# /flow:spike — 검증 (버릴 코드)

미검증 핵심 알고리즘·기술 리스크를 **`spike/` 아래 버릴 코드**로 확인한다.
계약도 완료 기준도 없다(학습 모드). **남기는 것은 지식이다** — 코드는 지운다.

> **왜 별도 국면인가**: 불확실한 구간은 계약을 아직 모르고 완료 기준을 못 정한다. 그래서 설계 국면의 계약 게이트·완료 기준·드리프트를 **끈다.** 불확실성이 풀리면 `/flow:design` 으로 넘어간다.

## 연결

정본은 `flow.topology.json` 의 `commands.spike` 다. **조각은 여기 적힌 것만 읽는다.**

| 무엇 | 이름 |
|:--|:--|
| 스킬 | `testing` · `plain-writing` |
| 조각 | `testing/run` |
| 에이전트 | `builder`(실험 코드 — 학습 모드) · `verifier`(가설을 돌려 판정) |
| 절차 조각 | `${CLAUDE_PLUGIN_ROOT}/procedures/spike/adr-handoff.md` |

## 게이트

진입 조건의 정본은 `flow.topology.json` 의 `commands.spike.entry` 다. **이 커맨드가 스스로 판정하지 않는다.**

- **기계** — 없다. 오히려 **`spike/` 는 소스 쓰기 게이트의 면제 대상이다**(`gate.exemptions` 의 `spike`) — 버릴 코드에 task 문서가 없는 것이 정상이다.
- **내용** — 없다. `entry.content` 가 비어 있으니 **여기서 `gatekeeper` 를 부르지 않는다.** 부를 자리를 만들려면 `flow.topology.json` 에 먼저 적는다 — 커맨드 본문이 게이트를 발명하지 않는다.
- **약속** — `throwaway`. **`spike/` 코드는 유지보수 자산이 아니다.** 아무 기계도 이걸 막지 않는다.

## 입력 (`$ARGUMENTS`)

| 인자 | 동작 |
|:--|:--|
| 가설 (필수) | 무엇이 되는지 확인하려는 것인가. 없으면 되묻는다 |
| `REFERENCE @파일` | 참고 자료·데이터·기존 코드 |
| 검증 기준 (필수) | 채택·기각을 가르는 **관찰 가능한 선**. 없으면 되묻는다 (끝없는 실험 방지) |

## 절차

**가설·기준 고정** — 인자에 없는 것만 하나씩 묻는다. 이미 인자·참조에 답이 있으면 건너뛴다.

| 물을 것 | 질문 예시 |
|:--|:--|
| 가설 | `무엇이 되는지 확인하려는 겁니까? (예: 결재선 규칙엔진이 500건/초를 견디나)` |
| 검증 기준 | `무엇을 보면 채택입니까? (예: p95 200ms 이하 · 오판정 1% 미만)` |
| 상한 | `어디까지 해보고 멈춥니까? (예: 접근 2가지 · 반나절)` |

```
[/flow:spike] 가설: {한 줄} · 검증 기준: {무엇을 보면 채택/기각}
         작업 공간: spike/00.{주제}/ (버릴 코드 — 게이트 면제 대상)
```

**최소 실험 코드** — `spike/00.{주제}/` 아래에만 쓴다.

- 폴더를 만들 때 **`README.md` 한 장을 먼저 둔다** — 나중에 이게 버릴 코드인지 아무도 모른다. 가설·검증 기준·시작일을 적고, 판정 뒤에 판정 결과와 ADR 경로를 채운다.
- 프로덕션 구조·계약·테스트 규약을 따를 필요가 없다 — **빠르게 답을 얻는 것이 목적이다.**
- 접근이 갈리면 각각 짧게 시도해 비교한다.

**관찰·측정** — 검증 기준에 대고 **실제로 돌린다**(`testing/run`). 추측과 측정을 구분해 적는다 — **측정 안 한 것을 측정했다고 하지 않는다.**

**판정·지식 이관** — 채택이든 기각이든 **반드시 ADR 로 남긴다.** 무엇을 어디로 옮기나는 `${CLAUDE_PLUGIN_ROOT}/procedures/spike/adr-handoff.md`.

**폴더 정리** — 판정이 끝났으면 **기본은 지운다.** 쌓이면 무엇이 무엇인지 알 수 없다.

- **묻고 지운다.** 사용자 확인 없이 지우지 않는다.
- **ADR 에 지식이 안 옮겨졌으면 지우지 않는다** — 먼저 옮긴다. `spike/*` 는 gitignore 라 **지우면 git 에도 없다.**
- 안 지우기로 했으면 그 폴더 `README.md` 에 판정 결과와 ADR 경로를 적고, **언제까지 남길지** 함께 적는다.

## 가드레일

- **spike 코드를 프로덕션으로 승격하지 않는다.** 검증된 것은 *지식*이고, 실제 구현은 `/flow:design` → `/flow:build` 로 다시 짠다.
- **`spike/` 밖에 코드를 쓰지 않는다.** 이 경로가 격리선이고 드리프트 오탐 방지선이다.
- **끝나는 조건 없는 실험을 하지 않는다.** 기준에 닿으면 멈춘다 — "더 다듬기" 로 새지 않는다.
- **기각도 기록한다.** 판정 없이 끝내지 않는다 — 안 남기면 같은 실험을 반년 뒤에 또 한다.
- **폴더를 사용자 확인 없이 지우지 않는다.** 복구가 안 된다.
- 커밋·push 는 이 커맨드의 일이 아니다.
