# /flow:publish — 발행

개발이 끝난 산출물을 **외부로 내보낸다.** 새 내용을 지어내지 않고 `doc/` 에 이미 있는 것만 구조화해 옮긴다.

> **외부 발행이다.** 내보낸 것은 공개·인덱싱될 수 있고 **되돌릴 수 없다.** 무엇을·어디로 발행할지 **확인받고 실행한다.**

## 연결

정본은 `flow.topology.json` 의 `commands.publish` 다. **조각은 여기 적힌 것만 읽는다.**

| 무엇 | 이름 |
|:--|:--|
| 스킬 | `doc-template` · `plain-writing` · `default-reference` |
| 조각 | `doc-template/diagram` · `default-reference/delegation` |
| 에이전트 | `explorer`(범위가 유닛을 넘을 때 — 산출물 원문을 메인으로 끌어오지 않는다) |
| 절차 조각 | `${CLAUDE_PLUGIN_ROOT}/procedures/publish/collect.md` · `${CLAUDE_PLUGIN_ROOT}/procedures/publish/url-record.md` |

**발행처의 기능 목록을 이 커맨드가 들고 있지 않는다.** 어느 서비스가 어느 다이어그램 형식을 렌더하는지는 가장 빨리 낡는 종류의 내용이다. **발행 시점에 도구 목록을 확인한다** — 미리 단정하지 않는다.

## 게이트

게이트 조건의 정본은 `flow.topology.json` 의 `commands.publish` 의 `entry`·`exit` 다. **이 커맨드가 스스로 판정하지 않는다.**

- **기계** — 없다. 외부 발행은 우리 훅이 닿는 곳이 아니다.
- **내용** — 없다. `entry.content`·`exit.content` 가 둘 다 비어 있으니 **여기서 `gatekeeper` 를 부르지 않는다.** 부를 자리를 만들려면 `flow.topology.json` 에 먼저 적는다 — 커맨드 본문이 게이트를 발명하지 않는다.
- **약속** — `external-confirm`. **사람 확인 뒤에 실행한다.** 아무 기계도 이걸 막지 않는다 — 그래서 약속이라고 적는다.

## 입력 (`$ARGUMENTS`)

| 인자 | 동작 |
|:--|:--|
| (비움) | 완료 산출물 전체(`project`)를 발행한다 |
| `{도메인}/{NN.유닛}` | 그 유닛만 |
| `→ 발행처` | 발행처 지정. 없으면 `workflow.config.json` 의 `publish` 설정, 그것도 없으면 **최초 한 번 물어 저장한다** |

## 절차

### 먼저 읽는다

**시작하기 전에 아래를 읽는다.** `## 연결` 의 표는 배선 선언이라 지시로 읽히지 않는다 —
실측에서 한 커맨드가 선언한 조각을 **하나도 안 읽고** 끝냈다(`build`, 0/7).
전체 경로는 **`${CLAUDE_PLUGIN_ROOT}/skills/{스킬}/references/{조각}.md`** 다 —
`references/` 를 빠뜨리면 파일이 없다(실측에서 한 번 그렇게 실패했다).
각 조각이 무엇의 정본인지는 그 파일 첫 줄에 있다.

- `doc-template` — `references/diagram.md`
- `default-reference` — `references/delegation.md`
- 절차 — `procedures/publish/collect.md` · `procedures/publish/url-record.md`

**대상 선언** — 무엇을·어디로 내보내는지 먼저 밝히고 **확인받는다.**

```
[/flow:publish] 대상: {유닛 경로 | project 전체}
           소스: {수집한 문서 묶음 — 아래 자료 수집}
           발행처: {대상}      갱신/신규: {판정과 근거 URL}
           다이어그램: {이미지 | 경로 참조 | 코드블록 그대로 — 그림 안 보임}
           민감정보: {발견 없음 | 아래 항목 제외 후 발행}
           → 외부로 내보냅니다. 진행할까요?
```

- **유닛을 넘으면 `explorer` 에 위임한다**(`default-reference/delegation`) — 항목만 받는다.

**발행처 확보** — 연결·인증은 **사람·기계당 한 번, 수동**이다. **인증을 AI 가 대신할 수 없다** — 미연결이면 방법을 안내하고 멈춘다. 발행 위치(부모)가 정해져 있지 않으면 **한 번 물어 설정에 저장한다.**

**자료 수집** — `${CLAUDE_PLUGIN_ROOT}/procedures/publish/collect.md`. **문서에 있는 것만 옮긴다.**

**민감정보 점검** — 외부로 나가면 되돌릴 수 없다. **내보내기 직전에 훑는다.**

| 무엇 | 처리 |
|:--|:--|
| 크리덴셜 · 토큰 · 키 | **제외** |
| 내부 호스트 · IP · DB 접속 정보 | **제외** |
| 개인정보 — 실명 · 연락처 · 계정 | **제외** |
| 비공개 경로 · 사내 시스템명 | 사용자에게 **확인** |

- 하나라도 걸리면 **목록을 보여주고 승인받는다.** 임의로 마스킹해 내보내지 않는다.

**발행** — 승인 뒤에 실행한다. 신규인지 갱신인지의 판정은 `${CLAUDE_PLUGIN_ROOT}/procedures/publish/url-record.md`.

- 실패하면 **멈추고 사유를 보고한다.** 다른 위치에 임의로 만들지 않는다.
- 일부만 발행됐으면 **어디까지 됐는지** 밝힌다.

**기록** — 발행 URL 을 남긴다. 어디에 남기나는 `${CLAUDE_PLUGIN_ROOT}/procedures/publish/url-record.md`.

## 가드레일

- **문서에 있는 것만 발행한다.** 추측·과장 금지 — 완료 기준·변경 사항은 실제 산출물 기준이다.
- **확인 후 발행한다.** 대상과 발행처를 사용자가 승인하기 전에 외부로 내보내지 않는다.
- **민감정보는 걸러 승인받는다.** 임의 마스킹으로 내보내지 않는다.
- **용어 문서를 빼고 발행하지 않는다** — 받는 사람이 나머지를 읽을 수 없다.
- **페이지를 임의로 새로 만들지 않는다.** 갱신 판정이 애매하면 묻는다.
- **다이어그램이 코드블록으로 남았으면 그 사실을 알린다.** 조용히 넘기면 받는 사람이 문서가 깨졌다고 본다.
- **읽어서 옮기는 것이다** — 코드·설계 문서를 고치지 않는다. 쓰는 것은 URL 한 줄과 내보낼 이미지뿐이다.
