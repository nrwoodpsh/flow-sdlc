# 02.decisions — 설계 결정 기록(ADR) 인덱스

전역 설계 결정(ADR)을 `/flow:sync`가 목록화한다. (아직 없음.)

| 번호 | 결정 | **상태** | 날짜 | 출처(유닛) |
|:--|:--|:--|:--|:--|

**`상태`를 반드시 채운다** — `제안` · `채택` · `기각` · `대체됨(→ NN)`.

- **기각도 목록에 남는다**(`/flow:spike`) — 상태가 안 보이면 **기각된 결정을 채택된 것으로 읽는다.**
- 값은 각 ADR의 `## 상태` 절이 정본이다. 여기는 색인이라 `/flow:sync`가 옮겨 적는다.
