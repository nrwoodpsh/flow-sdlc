- **합계는 분리해 센다** — `검증됨 12 · gap 3 · 사람 확인 2 · **현행(미검증) 41**`. 섞으면 gap 숫자가 의미를 잃는다.

- 상위 요구에 안 걸린 기능은 **"상위 미연결"** 로 표시한다.
