# /flow:spike — 판정과 지식 이관

**폴더가 사라져도 남는 것이 ADR 이다.** `spike/*` 는 gitignore 라 지우면 git 에도 없다 — ADR 이 자족해야 한다.

## 판정마다 무엇을 적나

| 판정 | ADR 상태 | 무엇을 적나 |
|:--|:--|:--|
| 채택 | `채택` | 검토한 안 · 왜 이걸 골랐나 · 감수하는 것 |
| 기각 | `기각` | **무엇을 해봤고 왜 안 됐나** · 측정값 · 다시 해볼 조건 |
| 조건부 | `제안` | 어떤 조건이 충족돼야 채택인가 |

**기각을 안 남기면 같은 실험을 반년 뒤에 또 한다.** 판정 없이 끝내지 않는다.

## 반드시 옮길 것

측정값은 **`측정` 절에 모아 적는다.** 검토한 안의 장단점에 섞으면 **수치인지 의견인지 구분이 안 된다.**

| 무엇 | 왜 |
|:--|:--|
| **측정값** — 수치 · 조건 · 환경 | 폴더가 사라지면 이것만 남는다 |
| **재현 명령** (있으면) | 다시 재려면 무엇을 돌리나 |
| **시도했다 접은 것** | 기각 사유가 없으면 또 해본다 |
| spike 폴더 경로 | **참고용이다** — 폴더가 없을 수 있다고 함께 적는다 |

## 어디로 가나

| 무엇 | 어디 |
|:--|:--|
| 판정 (채택·기각·조건부) | `doc/02.decisions/NN.내용.YYYYMMDD.md` + 그 색인 |
| 확정된 제약 — 성능 상한 · 기술 선택 | `doc/00.ref/00.architecture/` |
| 도메인 경계·용어 초안 | `doc/00.ref/01.domain/` — **소유와 확정은 사람이다** |

## README 가 둘이다

| 파일 | git | 무엇 |
|:--|:--|:--|
| `spike/README.md` | **추적된다** | "이 폴더는 버릴 코드" 안내. 세팅이 만든다 — **건드리지 않는다** |
| `spike/00.{주제}/README.md` | **무시된다** | 그 실험의 가설·기준·판정. **폴더와 함께 사라진다** — 그래서 정본이 ADR 이다 |
